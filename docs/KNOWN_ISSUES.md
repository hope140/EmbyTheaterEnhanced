# 已知问题与验证范围

当前渠道和下载见[README](../README.md#下载安装)。截至 2026-11-11，公开测试版为 v0.4.21，正式 Latest 仍为 v0.4.0。以下区分当前限制与已修复问题；历史用例只证明当时执行的范围。

v0.4.21 已公开发布为测试版。初始字幕优化与终止错误传递的源码、构建和有限验收范围见[本版核验](V0421_RELEASE_VERIFICATION.md)，不代表全面稳定性结论。

## 当前使用限制

- v0.4.21 只对当前代次的明确终止错误保留无重试分类；普通 EOF 仍可能错误地触发下一集。已用真实 adapter 与生成的 PlaybackManager 重放无错误 EOF 路径，结果仍允许下一集。不能仅按剩余时长、缓存 EOF 或单条 demux 警告认定失败。
- 初始字幕优化只有在实际轨道身份可准确映射时生效；未能确认时保留必要后置选轨。有限验收反馈为起播不卡、本地和被控端 CD2 直链正常，其他媒体、字幕及稳定性组合继续观察。

- v0.4.3 预览为一秒采样的低频视频截图，不合成字幕或承诺流畅视频。原任务栏两个控制按钮已移除，使用 Windows 系统媒体卡片；卡片布局由系统决定，停止不一定显示独立图标。
- v0.4.2 起的详情缓存只保存有限静态信息，不代替授权、最新进度或真实播放数据；HTTP 缓存统计不是海报独占大小，清理后可重新增长。
- 更新检查与下载需主动触发，不静默安装，也不提供降级。v0.4.5 起主动下载校验成功后会正常退出客户端并打开安装向导；v0.4.2–v0.4.4 仍需自行退出并安装。测试版版本高于正式版时，切换正式通道不会出现降级下载；见[更新步骤](USER_GUIDE.md#手动检查更新与通道)。
- v0.4.11 起可按顺序保存多个字幕首选语言；默认轨道实际由服务器返回的选轨结果决定，设置回读不等于真实选轨通过。
- 播放成功率退化和普通 Seek 后提前 EOF 的现场根因仍未确认。固定产品 DLL 的 138 次隔离对照未支持回退 `start` 时序，不等于已根治现场问题。v0.4.12 起的低频缓存／EOF 日志及后续诊断补充用于定位，不代表播放中断后的自动恢复；报告时请附发生时间与检查过的诊断片段。
- 自定义 STRM 规则原生优先时误报回退的修复，以及此前独立验收包中的弹窗隔离和诊断补充，已随 v0.4.20 测试版发布；这不等于播放成功率或 EOF 根因已解决。真实媒体与安装体验仍需用户继续验证。见[本轮验收边界](NEXT_RELEASE_SCOPE.md#本轮正式版与验收边界)。
- 下一集预载／预加载、播放／缓冲暂存和最近搜索已取消，提前下载继续保留。飞牛认证继续独立开发，安排在本轮正式版之后发布，真实认证和播放仍待验证；见[功能取舍](NEXT_RELEASE_SCOPE.md#功能取舍与后续范围)。

## 兼容与验证边界

- v0.3.2 起包含神医助手、Madby GenericUI 入口及 Backup & Restore 的兼容适配；后台与合成服务结果不等同于三个真实插件的前台通过。未支持的 DataGrid/PivotGrid 编辑器会明确失败，不加载额外外部脚本。详见 [兼容合同](PLUGIN_SETTINGS_COMPATIBILITY.md)。

- 曾报告的 STRM/115 内嵌字幕、音轨切换延迟，已按用户长期未再遇到的反馈记为已解决（2026-10-22）。这是问题状态更新，本次未追加性能修复代码。
- v0.3.1 仅在文件查询确认 NOT_FOUND 后有界刷新父目录并重查一次。映射不匹配、刷新失败、冷却或超时仍可能无法发现资源；请确认文件及映射，必要时在 CD2 手动刷新目录。
- 六项真实 CD2 验收为 USER_REPORTED_PASS；该用户反馈不等同于独立机器实测，也不覆盖所有服务、媒体与安装组合。
- Together 同步切集透明屏已修复，用户反馈正常；全屏短闪的合成采样未得出确定结论，不能保证全部硬件和媒体组合。
- Mixed-DPI、多显示器、HDR、Seek/Stop/退出时的短暂黑帧缺少全面验证。有新样本时请附版本和脱敏诊断。
- v0.3.13 修复 Helper 有 PID 时以真实 `exit` 确认进程终结，并使关闭时单项清理失败后仍继续结算其他步骤；本版没有增加整体退出期限或强退策略，未确认退出的 owned child/startup 仍可能继续等待，因此不代表解决所有 Electron 挂起或安装检测问题。真实故障注入未执行，详见[v0.3.13 核验](V0313_RELEASE_VERIFICATION.md)。
- 安装验证覆盖 v0.3.6 与 v0.3.8 之间的有界升级、允许降级、占用拒绝、卸载重装及一次 v0.3.8→v0.3.9 升级，见[v0.3.9 核验](V039_RELEASE_VERIFICATION.md)。v0.4.0 有有限安装、升级与使用验收，见[本版核验](V040_RELEASE_VERIFICATION.md)。这些结果不等于完整安装矩阵：空资料首次初始化、标准账户／UAC、人工取消、复制失败恢复及所有硬件组合仍有缺口；包体、合成界面与用户反馈分别记录，不能互相替代。
- 安装包未进行数字签名。只从项目 Release 下载并核对 SHA-256。
- 诊断脱敏覆盖已知格式，未知秘密格式不保证识别。上传前检查导出内容。
- 第三方对应源码、许可组合和部分资产条件仍有未解决项，见 [许可与材料风险](LICENSING.md)。

## 已修复问题与历史证据

- v0.3.14 的任务栏媒体控制销毁弹窗在 [v0.3.15](V0315_RELEASE_VERIFICATION.md) 修复。v0.4.3 又修复原生预览退出时访问已销毁窗口的异常、主窗口关闭收尾和 Electron 退出后的 Host 残留；当前安装入口见[README](../README.md#下载安装)。不同阶段修复不表示所有异常退出情形均已覆盖。
- v0.4.4 修复详情静态预览到完整页面的布局／海报交接，以及匹配身份和查询的驻留首页返回闪空。图片慢、失败、页面淘汰等仍按原加载路径处理，不代表所有服务器与硬件组合通过；见[发行核验](V044_RELEASE_VERIFICATION.md)。

遇到问题时，按[用户指南](USER_GUIDE.md#问题反馈)提供版本、发生时间、最少复现步骤与检查过的诊断片段。以上记录各自的验证范围，不代表所有服务器、插件、媒体和硬件组合均已通过。
