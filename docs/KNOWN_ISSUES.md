# 已知问题与验证范围

当前渠道和下载见[README](../README.md#下载安装)。以下区分当前限制与已修复问题；历史用例只证明当时执行的范围。

## 当前使用限制

- v0.4.3 预览为一秒采样的低频视频截图，不合成字幕或承诺流畅视频。原任务栏两个控制按钮已移除，使用 Windows 系统媒体卡片；卡片布局由系统决定，停止不一定显示独立图标。
- v0.4.2 起的详情缓存只保存有限静态信息，不代替授权、最新进度或真实播放数据；HTTP 缓存统计不是海报独占大小，清理后可重新增长。
- 更新检查与下载需主动触发，不自动安装，也不提供降级。测试版版本高于正式版时，切换正式通道不会出现降级下载；见[更新步骤](USER_GUIDE.md#手动检查更新与通道)。
- 下一集预加载、缓冲暂存、飞牛认证尚未发布，验证阶段各不相同，见[实验状态](NEXT_RELEASE_SCOPE.md#未发布实验)。

## 兼容与验证边界

- v0.3.2 起包含神医助手、Madby GenericUI 入口及 Backup & Restore 的兼容适配；后台与合成服务结果不等同于三个真实插件的前台通过。未支持的 DataGrid/PivotGrid 编辑器会明确失败，不加载额外外部脚本。详见 [兼容合同](PLUGIN_SETTINGS_COMPATIBILITY.md)。

- 曾报告的 STRM/115 内嵌字幕、音轨切换延迟，已按用户长期未再遇到的反馈记为已解决（2026-10-22）。这是问题状态更新，本次未追加性能修复代码。
- v0.3.1 仅在文件查询确认 NOT_FOUND 后有界刷新父目录并重查一次。映射不匹配、刷新失败、冷却或超时仍可能无法发现资源；请确认文件及映射，必要时在 CD2 手动刷新目录。
- 六项真实 CD2 验收为 USER_REPORTED_PASS；该用户反馈不等同于独立机器实测，也不覆盖所有服务、媒体与安装组合。
- Together 同步切集透明屏已修复，用户反馈正常；全屏短闪的合成采样未得出确定结论，不能保证全部硬件和媒体组合。
- Mixed-DPI、多显示器、HDR、Seek/Stop/退出时的短暂黑帧缺少全面验证。有新样本时请附版本和脱敏诊断。
- v0.3.13 修复 Helper 有 PID 时以真实 `exit` 确认进程终结，并使关闭时单项清理失败后仍继续结算其他步骤；本版没有增加整体退出期限或强退策略，未确认退出的 owned child/startup 仍可能继续等待，因此不代表解决所有 Electron 挂起或安装检测问题。真实故障注入未执行，详见[v0.3.13 核验](V0313_RELEASE_VERIFICATION.md)。
- 安装验证覆盖 v0.3.6 与 v0.3.8 之间的有界升级、允许降级、占用拒绝、卸载重装及一次 v0.3.8→v0.3.9 升级，见[v0.3.9 核验](V039_RELEASE_VERIFICATION.md)。v0.4.0 有有限安装、升级与使用验收，见[本版核验](V040_RELEASE_VERIFICATION.md)。这些结果不等于完整安装矩阵：空资料首次初始化、标准账户／UAC、人工取消、复制失败恢复及所有硬件组合仍有缺口；包体、合成界面与用户反馈分别记录，不能互相替代。
- 安装包未进行数字签名。只从项目 Release 下载并核对 SHA-256。
- 诊断脱敏覆盖已知格式，未知秘密格式不保证识别。上传前检查导出内容。
- 第三方对应源码、许可组合和部分资产条件仍有未解决项，见 [许可与材料风险](LICENSING.md)。

## 已修复问题与历史证据

- v0.3.14 的任务栏媒体控制销毁弹窗在 [v0.3.15](V0315_RELEASE_VERIFICATION.md) 修复。v0.4.3 又修复原生预览退出时访问已销毁窗口的异常、主窗口关闭收尾和 Electron 退出后的 Host 残留；当前安装入口见[v0.4.3 Release](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.3)。不同阶段修复不表示所有异常退出情形均已覆盖。

遇到问题时，按[用户指南](USER_GUIDE.md#问题反馈)提供版本、发生时间、最少复现步骤与检查过的诊断片段。以上记录各自的验证范围，不代表所有服务器、插件、媒体和硬件组合均已通过。
