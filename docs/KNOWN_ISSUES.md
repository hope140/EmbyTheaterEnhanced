# 已知问题与验证范围

- v0.3.2 起包含神医助手、Madby GenericUI 入口及 Backup & Restore 的兼容适配；后台与合成服务结果不等同于三个真实插件的前台通过。未支持的 DataGrid/PivotGrid 编辑器会明确失败，不加载额外外部脚本。详见 [兼容合同](PLUGIN_SETTINGS_COMPATIBILITY.md)。

- 部分 STRM/115 内嵌字幕和音轨切换有约 5–10 秒延迟；v0.3.1 未提供这项性能修复。
- v0.3.1 仅在文件查询确认 NOT_FOUND 后有界刷新父目录并重查一次。映射不匹配、刷新失败、冷却或超时仍可能无法发现资源；请确认文件及映射，必要时在 CD2 手动刷新目录。
- 六项真实 CD2 验收为 USER_REPORTED_PASS；该用户反馈不等同于独立机器实测，也不覆盖所有服务、媒体与安装组合。
- Together 同步切集透明屏已修复，用户反馈正常；全屏短闪的合成采样未得出确定结论，不能保证全部硬件和媒体组合。
- Mixed-DPI、多显示器、HDR、Seek/Stop/退出时的短暂黑帧缺少全面验证。有新样本时请附版本和脱敏诊断。
- 安装验证覆盖 v0.3.6 与 v0.3.8 之间的有界升级、允许降级、占用拒绝、卸载重装及一次 v0.3.8→v0.3.9 升级，程序、资料/DeviceId、退出码、登记与入口分别核对，固定 Inno 的两项延后残留单列。空资料首次初始化、标准账户/UAC 接受拒绝、人工取消与失败恢复仍有缺口；详见[v0.3.9 核验](V039_RELEASE_VERIFICATION.md)。v0.3.10 至 v0.3.12 完成包体与来源核验，未追加完整系统安装矩阵；v0.3.12 另有用户对本地包界面修正的认可，具体边界见[v0.3.12 核验](V0312_RELEASE_VERIFICATION.md)。
- 安装包未进行数字签名。只从项目 Release 下载并核对 SHA-256。
- 诊断脱敏覆盖已知格式，未知秘密格式不保证识别。上传前检查导出内容。
- 第三方对应源码、许可组合和部分资产条件仍有未解决项，见 [许可与材料风险](LICENSING.md)。

遇到问题时，按[用户指南](USER_GUIDE.md#问题反馈)提供版本、发生时间、最少复现步骤与检查过的诊断片段。以上记录各自的验证范围，不代表所有服务器、插件、媒体和硬件组合均已通过。
