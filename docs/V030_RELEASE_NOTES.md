# Emby Theater Enhanced v0.3.0

正式版发行说明已准备，公开发布尚待维护者授权；准确产物来源和摘要以本轮发行准备回执为准。

## 本次变化

- Windows安装器支持简体中文和英文，按Windows UI语言选择默认语言并保留后续选择；升级时显示目录页、预填原安装位置。
- 保留运行中安装/卸载保护提示和原有用户配置、DeviceId保留设计。
- 修复Together 1.6.0.5式PlayNow同步切集绕过本地Next/Previous入口时可能出现的透明屏：视频媒体替换统一复用原生持帧边界。
- 完善快速连续媒体替换、取消、失败/超时、视频转音频和Helper退出/重建时的持帧状态清理。

## 验证与已知质量范围

原PR29完整783/783回归、138/138独立审查及窗口合成视觉验证通过，保留各自源码身份；本轮复用相同产品输入，不重复播放实验。用户真实Together使用反馈正常；用户实际Windows覆盖升级成功，升级后启动及正常使用通过。安装器中文默认、手动语言及升级目录页面已有用户验收。
