# 已知问题

## Windows 多显示器不同缩放比例下的窗口尺寸异常

在 Windows 多显示器环境中，如果不同显示器设置了不同的显示缩放比例，例如一块显示器为 150%，另一块为 100%，少数情况下跨显示器移动播放器窗口、恢复窗口尺寸，或退出全屏恢复普通窗口时，窗口可能突然变大或变小。

### 可能出现的环境

该问题主要出现在同时使用多块 Windows 显示器，并且显示器采用不同缩放比例的情况下。现有复现与窗口在不同显示器之间切换、恢复窗口尺寸和全屏状态切换有关。

### 可能的表现

播放器窗口跨屏移动后，窗口占据的区域可能突然变大或变小。程序恢复之前的窗口大小时，也可能出现同样现象。退出全屏并回到普通窗口后，窗口尺寸偶尔会与进入全屏前不同。

全屏播放本身不代表一定会触发该问题，主要风险来自不同缩放显示器之间的窗口尺寸切换。

### 对播放的影响

目前已知影响集中在窗口尺寸管理。现有研究没有将它归因于媒体解码、播放进度或 Emby 播放会话，复现窗口问题时也不需要加载实际媒体。若同时遇到播放异常，建议将播放现象与窗口尺寸现象分开记录。

该现象在现有播放基线中可以独立复现，当前证据将它归类为 Electron 与 Windows 的窗口管理兼容性问题。现有证据没有表明它由 Enhanced 播放架构的新增组件引入。

### 当前状态

已知问题 / 暂缓处理

后续可以单独重新开启 Windows 多显示器缩放兼容性修复工作。

### 临时建议

- 如果窗口大小异常，可手动重新调整窗口大小。
- 如果经常在多块显示器之间移动播放器，尽量使用相同的 Windows 显示缩放比例，以降低触发概率。
- 全屏恢复后如果窗口尺寸不符合预期，可先手动调整窗口，再继续使用播放器。
