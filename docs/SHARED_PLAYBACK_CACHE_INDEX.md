# 共享缓存：有界增量索引

范围：独立 tools 原型的持久化改造。普通应用、授权／来源解析、默认媒体队列、预载选择和稀疏 seek 策略保持不变。仅本地合成数据，未访问真实外部媒体、未修改生产内核或发布。此前吞吐结果见[预算验证](SHARED_PLAYBACK_CACHE_BUDGETS.md)，本页取代其“最大窗口尚未实施”的阶段结论。

## 最小实现

- [index.cjs](../tools/shared-playback-cache/index.cjs) 只负责元数据格式及有界重放，不执行网络／文件 IO。v2 快照保留原身份散列，将块压成 start／length／hash／touched 四元组，文件名由已验证的散列和范围派生，不重复存长文件名。可读取旧 v1 快照并原子迁移，不复制媒体。
- [store.cjs](../tools/shared-playback-cache/store.cjs) 对完整块新增与淘汰写 add／remove 记录。每帧带连续序号和 SHA256 摘要；日志最多 1MiB、每 512 帧前归并。结构／媒体角色变更仍写完整原子快照，减少协议面。
- 快照仍最多 2MiB，总条目／块／退休／待写行数上限为 16384，足够目标 14288 个满块及元数据。字节数、行数双重检查保持；不是单纯放宽旧 4096 行限制。
- 归并发生在追加下一帧之前，只快照已发布状态。写完整媒体临时块、rename 到最终文件、追加并验证日志成功之后，才把新块发布为可读。删除顺序为 remove 提交、撤出可读索引、等待租约释放、再 unlink。满窗滚动也走 remove 增量记录。
- 快照先 rename，日志后重置。恢复校验帧摘要和连续序号，跳过快照已覆盖的有效旧帧；只丢弃不完整末帧，完整坏帧／重复／跳号均拒绝。最终引用再核媒体文件长度和 SHA，未提交或不再引用的孤块清理。
- 日志写入先核现存文件的 lstat、打开句柄的 fstat 和当前路径身份，再通过同一句柄循环 write 或 truncate；首次创建使用 wx。短写按 bytesWritten 推进，零进展失败并禁止继续正常写入，不重新按路径打开追加／截断。
- 全局 payload admission 仍在复制／预留前核 M+P，包括退休租约、孤儿和待写。角色租约迁移瞬态、元数据开销另计；没有增加用户选项或默认 RAM 预算。

这里验证的是进程退出／中断及原子提交顺序。没有新增 fsync 或跨设备持久性协议，**不宣称断电持久性**；旧原型打开新格式会拒绝，回退代码不能假装兼容 v2 数据。

## 真实落盘：3072MiB + 500MiB

使用同一 Linux x64 云容器、Node v24.18.1、overlay 文件系统，底层设备／共享宿主负载未知，OS 页缓存未清；测试不等于实体慢盘或 Windows。一个 256KiB 固定合成 Buffer 逐块写真实文件，代表 4GiB 逻辑来源，没有整片内存镜像、HTTP 下载或解码。两个场景共约 51.85 秒，显式总截止 600 秒。

两个窗口分别填满并验证连续区间及首／中／末块 SHA：

| 项目 | M300／P100MiB | M3072／P500MiB |
| --- | --- | --- |
| 同时留存 payload | 419430400B（400MiB） | 3745513472B（3572MiB） |
| 完整块数／有效索引行 | 1600／1602 | 14288／14290 |
| 满窗时 checkpoint | 153364B | 1390592B |
| 满窗时 journal | 17554B | 128064B |
| 满窗时有效元数据文件长度合计，不含 owner | 170918B | 1518656B |
| 全场景 checkpoint 逻辑写入 | 1109297B | 27281849B |
| 全场景 journal 逻辑写入 | 438850B | 3940815B |
| 全场景元数据逻辑写入合计 | 1548147B | 31222664B |
| 全场景归并次数 | 6 | 30 |
| 操作边界采样 RSS 峰值 | 127275008B（121.38MiB） | 264241152B（252MiB） |
| 重开 createStore 耗时 | 737.45ms | 7099.15ms |
| 场景总耗时 | 3.98s | 47.87s |

“全场景”包含填充、两次越额尝试、Stop／重开及实际 C 切片，不只是首次写入。每个角色超一块都拒绝，并按原回收策略各淘汰一块；重开因此实际恢复 A 为 299.75／3071.75MiB，B 按合同丢弃，不能说越额实验后仍保留完整 M。准备 C 保留 A，actual(C) 后才删除 A，最终只留 C 的 256KiB。

独立文件 IO 计数与 store 指标相等：记录完成的 checkpoint 写入和句柄实际 journal bytesWritten，不把预留、计划 Range 或设备扇区当成写入量。所有阶段无临时残留；全程物理媒体文件逻辑长度峰值等于 M+P。最大场景元数据文件共存峰值 2955856B（含旧／临时快照及日志），完整文件逻辑长度的同时峰值 3748207184B，二者峰值不必发生于同一时刻；文件系统实际分配量另存，不混为逻辑长度。

同口径 300／100 场景，旧全量索引累计逻辑写入 379669672B，本轮 1548147B，约减少 99.59%。旧最大场景在约 1GiB 已截断，与新 3.5GiB 完整场景负载不同，不据此编造同负载速度倍数。最大场景仅约 1.52MB 的有效快照＋日志即可描述窗口；没有累计整片第二份缓存。

RSS 是操作边界观测值，不是硬上限；两场景顺序同进程执行，allocator／GC 历史计入。恢复仍逐块读出并验证约 3GiB SHA，观测 7.10 秒。该耗时是未来普通入口接线的真实边界，不能把 store 填满成功宣传成启动／播放无感。前台有界队列仍为原值，尚未实施惰性恢复或改变完整性验证。

## 中断恢复与滚动验证

14 项定向索引测试覆盖：

- v1 对象块到 v2 四元组迁移，2MiB 快照、1MiB 日志和16384行边界；
- 完整 add、半帧末尾、坏摘要、重复／跳序、越界范围；
- 真子进程在 add 后未 close 即退出，新 store 读回正确字节；
- checkpoint rename 后、日志 reset 前退出，重开不重复块；
- remove 提交后、unlink 前退出，旧块不会复活；
- 句柄短写／零进展不发布块，append 在 lstat 后或 open 后替换链接、reset 替换链接，外部哨兵均不变；
- 700 个不同的 16B 块经过八块满窗滚动，add／remove 都进入日志，checkpoint 远少于块数，最后八块重开后完整可读。

满窗拒写会异步安排回收；测试采用有界重试并让出事件循环，不能用密集 setImmediate 重试当作文件 IO 已完成的屏障。

## 原预载链回归

同一已固定 400 秒 NUT、300MiB 前缀、mpv 300MiB 窗口与既有 Linux 实验库标准 C API，三次／目标／路径共 18 样本。不是 Windows、实际屏幕呈现或普通应用入口。默认 sparse 策略、源访问检查和能力 URL 未改变。

| 目标 | 直连首帧／seek 中位 | sparse 首帧／seek 中位 |
| --- | --- | --- |
| 60 秒，缓存内 | 404.34／127.84ms | 191.08／7.54ms |
| 350 秒，缓存外 | 401.52／128.93ms | 192.11／129.59ms |

12 个候选首帧／目标帧 RGB 匹配直连；所有所属进程、句柄、socket、写作业及存储正常关闭。默认 sparse 启动和两个 seek 目标重复接收已准备前缀正文均 0B，访问探测每次另计 1B。缓存内 seek 源正文 0B；缓存外为 1773568／1839104／921600B，均不与前缀重叠。coherent 仍只为负面对照，实际重复前缀约 11.35–16.79MB，未采用。

观察的是代理实际收到的已校验正文，不是播放器消费量或计划 Range。三样本不是 p95 承诺；没有重跑旧20对冷启动或吞吐矩阵，也未取消其早期首帧失败／边界结论。
