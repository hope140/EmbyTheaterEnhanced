# v0.4.15 播放中调整字幕外观候选

## 范围与参考

2026-11-05 只读核对 Emby 网页端 `app.emby.media/videoosd/videoosd.js`、`modules/subtitleappearancedialog/subtitleappearancedialog.js`、`settings/subtitleappearanceeditor.js` 和编辑器模板：当前网页端从播放字幕菜单进入“字幕外观”弹窗，使用同一用户设置的字号、文字颜色、阴影、背景色和透明度字段；对文本字幕显示入口，ASS/SSA 不走普通外观设置。仅参考行为，没有将该网页端源码或模板纳入仓库。

ETE 沿用现有 `localplayersubtitleappearance3` 设置，在播放 OSD 的字幕菜单添加弹窗。每次选择立即写入当前账号的本机用户设置，并向当前原生 libmpv 代次提交对应属性；关闭弹窗不停止播放。弹窗随字幕轨切换、播放停止、OSD 离开和销毁而关闭。远控播放器及图片字幕不显示入口。现有设置页、字幕搜索、字幕偏移、轨道与会话归属不变。

原生映射沿用已支持的字号、文字颜色、背景色和透明度。为处理播放中清除阴影效果，额外开放 `sub-outline-size`、`sub-shadow-offset` 两个受限属性；`none`、`uniform` 与默认可分别重置，`raised`/`depressed` 只能映射为 libmpv 的相同近似阴影，不能复制浏览器的上下方向叠影。mpv 对 ASS/SSA 和图片字幕不保证应用普通文本样式，因此入口避开这些格式。原有字号档位保持；当前 mpv 0.41 默认普通字号为 38，历史 ETE 自定义“小”档位数值为 45，这个旧档位顺序问题本轮不改变，现场验收时应观察。

## 验证与验收

- 本地 Node 定向测试覆盖设置转换、当前播放即时写入、默认恢复、停止后拒绝旧写入和下一次播放取持久设置；构建输入与 Web overlay 的固定源哈希约束继续验证。
- 隔离 Chromium DOM 探针验证五个字段呈现、透明背景时隐藏透明度、改动保存和调用当前播放器、关闭后移除弹窗。这是隔离界面验证，不等于完整客户端视觉或实际字幕渲染。
- 待 Windows 构建和真实客户端验收：播放普通 SRT/WebVTT 文本字幕，打开字幕菜单中的“字幕外观”；改字号、颜色、阴影、背景与透明度，观察当前画面和重新播放；切换字幕轨、停止、返回后检查弹窗收尾。ASS/SSA、PGS 不应出现入口；观察遥控焦点和浅深主题。当前用户 NAS 与实际字幕素材未由本开发环境访问。
