# 提前下载独立包手动验收

本清单用于独立分支的提前下载候选，不表示正式版已有此功能。候选同步 main `a958d52ea1dc866c0852d3158c0063a9bf75a4c5`，版本沿用 **0.4.6**，含该基线的 STRM 配置保存修复，不包含独立预载／暂存分支。

安装包名称必须含 `0.4.6-test-<source前12位>-<run>-<attempt>`；准确完整源码、大小、SHA256 以同一次 Actions artifact 的 `test-build-summary.json`、安装包 `.provenance.json` 和 `.sha256` 为准。不能用已发布的普通 v0.4.6 或旧下载分支 CI 结果替代本次候选。构建／下载位置由交付消息给出；Actions artifact 默认保留一天。

自动化检查覆盖合成服务、实际磁盘／进程重启和 Windows 文件提交，不代替以下真实服务器、原生目录选择器和可见播放验收。

## 准备

1. 正常退出正在运行的 ETE，再由使用者手动运行本次测试安装包。它沿用 ETE 的安装身份／配置；不是自动隔离 profile 的便携版，也不会由助手代为安装或操作前台。
2. 登录原服务器，确认原 STRM／CD2 设置可正常播放，服务器允许该账户下载。无需清空登录／设置、修改服务器数据或开启缓存实验。
3. 准备两个专门测试的空目录 A、B。第一轮先用本地 NTFS；FAT/exFAT、网络盘和移动盘属于后续独立兼容性项目。
4. 选择一部原来可正常播放的 STRM／CD2 视频，记下媒体版本。若有多个版本，明确选择同一版本下载和播放。另选第二部视频用于目录切换测试。

## 1. 真正视频与首次目录记忆

先播放测试视频，打开播放器的播放统计，在 **Emby Theater Enhanced** 栏记下原来的“播放源”（如 CD2 DirectUrl、CD2 HTTP、Emby 原生），然后正常停止。

先在下载管理点击选择目录并取消，确认仍显示尚未选择；再点击影片原来的“下载”按钮，应重新弹出选择器，选择目录 A。影片菜单只保留一个“下载”，不显示旧“下载到设备”。进入 **设置 → 下载管理** 查看任务。

看到明显进度后即可接着做第2步，再等待完成；这样通常两部测试视频就足够。

预期：

- 出现等待／下载中状态、实际字节和百分比进度；任务目录为 A。点击默认目录或任务的“打开文件夹”应打开对应目录；完成后管理页显示完整文件路径。
- 没有每次重复弹出目录选择器。再次点击同版本下载不会并行创建重复任务。
- 完成后产生可用的普通 `.mkv`／`.mp4` 等视频文件；任务变为“已完成”。可以用使用者自己的播放器打开这份测试文件，确认它是影片而非 STRM 地址文本／登录页。
- 服务器只返回指针、网页、分段流或无法核验长度时，显示未完成及具体阶段／原因，不伪装成已完成视频。来源预检诊断保留于当前进程，可直接重试；退出后不保留这种尚未进入传输的诊断。若失败，请记录阶段和提示原文，不先清空设置。

若本来有不同的 DirectUrl／CD2 HTTP 测试片源，可分别重复；不必为了验收擅自修改全局映射或服务器权限。

## 2. 正常关闭与跨应用续传

选择一个尚未完成、需要一定时间才能下载的测试视频。已有明显进度后，记下设置页字节数，正常关闭 ETE。等待片刻，再打开**同一测试安装**并登录**同一服务器账户**。

预期：

- 关闭后停止传输，不要求应用后台常驻；未完成任务及其临时文件保留。
- 重新登录后自动继续，原任务仍使用 A；大文件重新校验已存前缀可能需要时间。
- 来源保持相同、支持安全 Range 且有强校验器时，从已提交偏移继续；完成文件能正常播放。
- 无法安全续传或来源变化时，明确提示从头下载自己的未完成文件，进度可能回到零。这是保护行为；不能承诺所有 STRM／CD2 来源都能续传。
- 不手工重命名、截断或删除 `.part` 文件，不通过制造系统断电验证本步骤。强制结束的协议／文件检查已有合成子进程测试，真实机器断电另计。

若出现错误，记录“关闭前进度／重开后进度／提示原文／最终是否完成”，不要先清理任务或配置。

## 3. 更换默认目录

在“设置 → 下载管理”将默认目录改成 B，再为一部尚未创建下载任务的测试视频创建新任务。不要用已完成的同一版本检查新目录；它会复用已有完成文件。若第2步另开了一个样本，此处再选一个新样本。

预期：新任务默认使用 B，不重复询问目录；A 中已完成文件不移动、不删除，原有未完成任务继续使用 A。重开 ETE 后默认目录仍是 B。

## 4. ETE 中本地优先播放

保持服务器在线，重新播放**已下载完成的同一媒体版本**。打开播放统计的 **Emby Theater Enhanced** 栏。

预期：

- “播放源”显示 **已下载文件**，画面／声音正常，拖动进度可用。
- 播放进度、暂停、退出后重新进入以及原来使用的远控行为正常；不建立另一套离线媒体库。
- 仍可能有在线授权和少量来源校验请求，不能用“完全零网络请求”作为判据。
- 明确走服务器 Transcode 的播放保持原转码链，不把它算成本地命中失败。

可选回退检查：停播后仅将**本轮新下载的测试文件**改名保留，再播放该条目。应回到原在线来源，不误用同名替换文件、不删除改名后的文件。此项不要操作原有个人媒体。

## 5. 登录／链接失败处理

正常使用中若遇到登录失效、签名链接过期、目录不可用或空间不足，记录任务页提示。重新登录或恢复目录条件后，使用任务的“继续”入口。

预期：失败不把错误正文保存为完成影片；未完成任务保留。签名刷新必须仍是同一表示，不能把新版本字节追加到旧文件。不需要为了本轮验收退出服务器授权、修改片源或主动耗尽磁盘。

程序已用回环 HTTP 验证“初次传输 401 后重取链接”和“断流续传时 401 后重取链接”的最终字节一致；真实服务器的 401／换签是否兼容，仍以本次手动结果为准。

## 反馈格式

记录候选源码前12位、每项通过／失败、原播放源、下载后播放源、关闭前后字节数与错误提示即可。多版本请注明是否始终选择同一版本。不要直接粘贴 Token、带签名的完整 URL、账号信息或未脱敏诊断。

必须通过：真实影片下载、正常重开后的安全继续／明确重下、目录记忆及切换、同版本本地命中播放。实际 FAT/exFAT、网络盘、拔插／断电及完全离线启动不计为本轮已通过。


## 7. 暂停、继续、文件位置与删除

1. 在专门测试视频下载中点暂停，确认字节停止增长；重开并登录后仍保持手动暂停。点继续后重新核验并按支持情况续传。顶部全部暂停／继续应只操作当前账户任务。
2. 已完成文件移到临时测试子目录后刷新：应显示未找到文件并保留记录。把测试目录暂时断开或重命名时应显示目录暂不可用，恢复后重新检查，不能自动清记录。不要用真实移动盘断电模拟本项。
3. 对专门的测试下载选择删除，先取消，记录和文件应保持；再次确认且不勾选永久删除，记录应清除，视频／.part文件保留。可以勾选多个任务走同一流程。
4. 永久删除仅用可丢弃的专门下载夹具验证：确认窗口默认不勾选，只有主动勾选才删除核验通过的本任务文件。被改写／替换的文件、不可用目录和不明确的提交结果应保留记录并报告失败。不要拿用户已有文件验收。
5. 关闭STRM解析后的下载若仍失败，记录下载管理中的阶段、HTTP状态和来源类别；原Emby下载接口与播放接口可能返回不同内容，不能从“可播放”推定下载接口成功。打开解析后的新任务应显示实际取源类别；旧任务来源不做猜测。
