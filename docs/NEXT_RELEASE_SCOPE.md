## 当前发布边界（2026-11-11）

正式 Latest 为 [v0.4.0](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.0)，最新公开测试版为 [v0.4.21](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.21)。0.4.21 已发布并同步文档，不再列为“待出验收包”或“待测试发布”。下载与证据见[项目首页](../README.md#下载安装)及[本版记录](V0421_RELEASE_VERIFICATION.md)。公开安装器整文件匿名下载曾超时，未补验前不记为完整下载通过；Actions 完整包和公开附件身份核验分别保留。

## 本轮正式版与验收边界

本轮以当前测试版稳定后准备正式版为目标，不插入新功能，也不预先占用版本号或承诺发布日期。ETE 0.4.21 继续正常使用观察；已有字幕起播不卡、本地播放和被控 CD2 直链正常的有限反馈，不等于所有媒体、设备及长期播放已验证。

EWT 已获阶段性使用验收通过，继续观察稳定性；其最新版本与后续问题以 [EWT 项目](https://github.com/hope140/EmbyWatchTogether)记录为准，不在本仓库复制版本状态。ETE 正式版准备也以 EWT 稳定及 ETE 自身使用反馈为条件；这不是两个项目代码或发布流程耦合，也不是自动发布授权。正式版发布和受保护分支合并仍须明确确认。

播放成功率退化和提前 EOF 的原始读取原因仍未确认。0.4.21 只对归属明确的终止错误走既有错误退出；普通、无明确错误的 EOF 仍可能自动下一集。不把未复现当作根因已修复，不以时长猜测、自动重试或新内核方案擅自改变正常播放。技术限制见[已知问题](KNOWN_ISSUES.md)。

## 正式版后的精简候选

局域网唤醒（WOL）与服务器自动发现当前缺少实际使用需求，列为本轮正式版之后的精简候选。本轮只记录方向，不删除功能。删除前核对自定义协议、AMD 动态注册、API／连接管理器消费者和构建投影，并验证手动输入服务器地址、已保存服务器连接及重连不受影响。保留用户已有连接资料与配置，不把静态无直接 import 当作无调用证据。

其他整理先做可证明无行为变化的局部清理；播放请求、Session、Native Helper 生命周期及取消／回退边界维持既有归属。CEC、旧 PPAPI 和 CustomCssJS 已完成的退役不重新立项，必要历史来源与许可记录保留。

## 其他条件候选

- 显示工具目标选择、跨 renderer 同值恢复及完整退出恢复仍需明确归属与硬件验证；现有有限守卫不等于全局显示状态事务。
- 安装验证只覆盖已记录的有界场景。空资料首次初始化、标准账户／UAC、人工取消、复制失败恢复等缺口按独立可回退环境安排，不把包体检查当成完整安装矩阵。
- 签名、圆角、整树 Web、新编辑器、自动内核更新及跨平台等继续按具体需求与条件选择，旧计划不构成实施或发布承诺。
- CEC 已退役，不再安排 CEC 功能验收；WOL 和服务器发现按上方正式版后精简候选处理。开机启动的历史盘点不代表真实系统写入或使用结果，旧计划不增加本轮范围。
