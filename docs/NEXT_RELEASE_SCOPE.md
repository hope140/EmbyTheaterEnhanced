- 签名继续暂缓；不采购证书、不改变当前NotSigned事实或发布渠道。
- 缓存继续暂缓；STRM/115字幕、音轨切换延迟无限期延期，只有用户明确恢复时才重启该主题。
- 圆角及缺硬件的显示组合不进入本次实施。缺条件保持未验证，不阻塞独立的代码与文档维护。
- 整树Web、新Grid/provider、自动内核更新、Shader库和跨平台仍需独立规格，不把已交付组件重新包装成这些功能完成。
- 可选系统集成的需求选择包括具体设备/遥控目标、需要唤醒哪类已有服务器、发现网络边界，以及开机启动对象/用户与退出语义。本次只列条件，不设置默认勾选或擅自写系统配置。
