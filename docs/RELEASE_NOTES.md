# v0.4.13 测试版

Windows x64 **Pre-release 测试版**。可手动下载，或在“关于 Enhanced”选择测试通道后主动检查更新。当前正式版仍为 [v0.4.0](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.0)。

## 本次更新

- 首选音轨语言现在可选择多个；已选语言在选择弹窗中置顶，可通过拖动手柄或上／下图标按钮调整顺序。设置页只显示已选结果。
- 现有字幕首选语言多选也可在原选择弹窗中按同样方式调整顺序。两项设置保存到 Emby 用户配置；实际播放轨道仍由服务器决定。
- 保留 v0.4.12 的更新交接修复与提前 EOF 定位日志，本版不修改播放器选轨或 EOF 行为。

## 验证范围

设置页、来源合同和构建结果以本版准确源码的核验回执为准。真实服务器对逗号分隔优先序的解释、旧服务器兼容、遥控焦点、实际选轨和安装体验仍需现场验收；设置保存成功本身不证明实际选轨。方法见[本版候选核验](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/V0413_LANGUAGE_PREFERENCES.md)。

## 下载安装

从本 Release 的实际附件区下载 Windows x64 安装包与对应 .sha256 文件，勿将源码压缩包当作安装包。安装器未签名；手动安装前核对同版本 SHA-256 并正常退出客户端。安装与更新说明见[用户指南](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/USER_GUIDE.md)。
