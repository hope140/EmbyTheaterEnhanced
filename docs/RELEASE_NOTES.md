# v0.4.11 测试版

Windows x64 **Pre-release 测试版**。可手动下载，或在“关于 Enhanced”选择测试通道后主动检查更新。当前正式版仍为 [v0.4.0](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.0)。

## 本次更新

- 字幕首选语言支持按所选顺序多选，并在重新进入设置页时保留选择。清空选项仍表示不指定首选语言。
- 继续使用既有用户配置字段；播放时实际默认字幕轨道仍由服务器返回值决定。本版保留 v0.4.10 已发布的功能。

## 已知问题与验证范围

设置页多选与保存已有自动回归和用户验收；旧版服务器对多语言配置的实际解释、真实服务读回与播放选轨仍需实际环境确认。本版不包含独立更新退出／安装交接修复或新的提前 EOF 定位日志。准确源码、Windows CI、包体和证据边界见[本版核验](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/V0411_RELEASE_VERIFICATION.md)。

## 下载安装

从本 Release 的实际附件区下载 Windows x64 安装包与对应 .sha256 文件，勿将源码压缩包当作安装包。安装器未签名；手动安装前核对同版本 SHA-256 并正常退出客户端。安装与更新说明见[用户指南](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/USER_GUIDE.md)。
