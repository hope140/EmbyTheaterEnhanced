# v0.4.21 测试版

Windows x64 **Pre-release 测试版**。可手动下载，或在“关于 Enhanced”选择测试通道后主动检查更新。当前正式版仍为 [v0.4.0](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.0)。

## 本次更新

- 在实际轨道身份可准确匹配时，提前选择默认内嵌字幕，减少起播后再次选轨带来的额外定位；保留外挂转内嵌、Index=0 和播放中正常切换。不确定时保留原有后置选轨。
- 补齐当前播放代次的明确终止错误传递，避免错误类型丢失后进入自动下一集或同集转码回退；旧代次和重复错误不会重复结束新的播放。不增加应用自动重试。
- 同步用户指南、已知问题和版本核验记录。验收版本有字幕起播不卡、本地播放及被控端 CD2 直链正常的有限用户反馈，其他稳定性继续观察。

## 已知问题

**没有明确终止错误、只上报普通 EOF 的提前结束仍可能自动下一集。** 本次没有按剩余时长或单条解复用警告强行判错；真实事件序列重放仍显示该路径允许下一集。原始 MKV 读取异常和现场提前 EOF 根因尚未确认，字幕优化不等于修复读流故障。

初始选轨优化依赖准确映射，不保证所有媒体都消除额外定位。有限使用反馈、隔离测试和包体校验不代表所有服务器、媒体、设备及安装组合通过。准确来源和验证范围见[本版核验](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/V0421_RELEASE_VERIFICATION.md)。

## 下载安装

从本 Release 的实际附件区下载 Windows x64 安装包、同名 .sha256 与来源记录；SHA256SUMS.txt 列出发行文件摘要。不要将 Source code 压缩包当作安装包。安装器未签名；手动安装前核对 SHA-256 并正常退出客户端。见[用户指南](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/USER_GUIDE.md)。

已使用 0.4.21 独立验收包的用户，因版本号相同，内置更新检查不会提供同版本覆盖升级；若要切换到本 Release 的标准发行包，请核对实际附件后手动安装。验收包与发行包分别记录源码及哈希，不将旧包改名冒充新构建。
