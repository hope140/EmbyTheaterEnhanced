# v0.3.11 · 页面布局修正测试版

Windows x64 **Pre-release 测试版**，请手动下载。当前正式版为 [v0.3.1](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.3.1)。

## 本次更新

- 修复插件设置页被旧全局限宽压窄的问题，页面可按自身布局显示内容。
- 收窄STRM智能解析设置表单，保留左对齐和窄窗口自适应。
- 普通设置页默认限宽、影片简介折叠及其他设置页布局保持。

本版为界面维护更新。准确来源、构建和包体结果见[发行核验](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/V0311_RELEASE_VERIFICATION.md)。

## 已知问题

STRM/115内嵌字幕和音轨切换延迟尚未解决，多显示器目标选择与完整退出恢复仍有验收边界。本次页面验证不代表重新完成系统安装或真实播放/远控验收。更多内容见[已知问题](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/KNOWN_ISSUES.md)。
