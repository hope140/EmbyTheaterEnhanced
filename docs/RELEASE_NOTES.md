# v0.4.14 测试版

Windows x64 **Pre-release 测试版**。可手动下载，或在“关于 Enhanced”选择测试通道后主动检查更新。当前正式版仍为 [v0.4.0](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.0)。

## 本次更新

- 首页可按服务器设置显示更多媒体分区类型，并沿用服务器提供的分区顺序、标题与内容；`Thumb` 图像选项使用现有横向卡片。暂不支持的按钮、列表、Spotlight、垂直布局及非默认卡片尺寸仍回到原首页。
- 缩小窗口时，少量条目的服务端首页分区与较多条目的同形状卡片保持一致的响应式宽度。横图与竖版海报仍按各自图片比例展示。
- 沿用 v0.4.13 的语言偏好。搜索页保留原“猜你喜欢”和正常搜索，不包含最近搜索记录功能。

## 验证范围

首页布局和缩放已在合成服务端数据、冻结网页组件与不同窗口宽度下验证；用户 NAS 的实际分区响应、Windows 前台焦点、安装与播放组合需以现场体验为准。支持范围和回退条件见[首页合同](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/SERVER_HOME_SECTIONS.md)。

## 下载安装

从本 Release 的实际附件区下载 Windows x64 安装包与同名 `.sha256` 文件，勿将 Source code 压缩包当作安装包。安装器未签名；手动安装前核对 SHA-256 并正常退出客户端。安装与更新说明见[用户指南](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/USER_GUIDE.md)。
