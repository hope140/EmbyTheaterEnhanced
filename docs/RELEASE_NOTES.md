# v0.4.17 测试版

Windows x64 **Pre-release 测试版候选**，尚未发布。发布后可手动下载，或在“关于 Enhanced”选择测试通道后主动检查更新。当前正式版仍为 [v0.4.0](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.0)。

## 本次更新

- 修复服务器指定默认音轨索引为 0 时，开始播放未应用该选择的问题；保留原音轨编号转换及转码处理。
- 播放信息请求最多等待 30 秒，停止上报最多等待 10 秒，期限包含响应正文读取。停止上报失败后本地换片可以继续；保留取消和会话归属，不自动重试请求。

## 已知问题

较慢服务器的播放信息请求可能在 30 秒后失败。停止上报超时可能使服务端最终进度未保存，客户端不会将其标记为成功。本版不涉及提前 EOF、字幕映射、播放器设置恢复、直链回退或挂载探测策略，也不表示历史偶发播放问题已全部解决。

候选提交的 Windows 固定材料、包体及真实服务器播放仍需验收；已完成的源码测试不能替代这些验证。实际版本和来源以验收通过后的包及来源记录为准。

## 下载安装

发布后从本 Release 的实际附件区下载 Windows x64 安装包、同名 `.sha256` 与来源记录；`SHA256SUMS.txt` 列出发行文件摘要。勿将 Source code 压缩包当作客户端安装包。安装器未签名；手动安装前核对 SHA-256 并正常退出客户端。操作说明见[用户指南](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/USER_GUIDE.md)。本候选不复用旧版本验收包或其哈希。
