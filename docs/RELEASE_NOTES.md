# v0.4.18 测试版

Windows x64 **Pre-release 测试版**。可手动下载，或在“关于 Enhanced”选择测试通道后主动检查更新。当前正式版仍为 [v0.4.0](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.0)。

## 本次更新

- 补齐播放停止、替换及队列变化的定位日志，记录停止请求时最近已知的播放／缓存状态、观察时间和请求归属；增加可读的输入域名、端口、安全路由结构及运行内定位指纹，保护签名、Cookie 和认证信息。
- 当前集最终播放失败时，沿原流程退出播放并清理队列，不再因错误提示结束而自动跳到下一集。正常播完自动连播、主动切集及原有同集兼容流处理保留。
- 主视频起播前加载失败时，按现有配置顺序尝试尚未尝试的后续路线；每条最多一次，整个过程有界，并保持同一播放请求。切集、退出或新播放会取消旧尝试；字幕错误、主动停止及播放器进程故障不触发路线回退。后续路线耗尽后保留原有同集兼容流处理，最终失败退出。

## 已知问题

历史偶发提前停止的具体触发原因仍未确认。本版补充定位证据，不表示已修复其未知根因。播放器 HTTP 日志缺少资源标识，403 等响应仍只能关联到 helper，不能据此认定属于主视频、字幕或某次输入地址；输入域名也不代表重定向终点。

路线回退仅覆盖起播前的主视频加载失败，不处理播放到一半的恢复，也不保证取得新地址或恢复成功。匹配启用规则的 STRM 视频从首次进入路线序列起，共享 15 秒解析与加载期限，至 core-playing 结束；不包含此前的 PlaybackInfo、配置快照、窗口/helper 准备、身份恢复和本地下载校验，也不限制之后原有的同集转码兼容尝试。同步文件检查阻塞时需恢复执行后才能检查超时，不构成硬实时保证。失败时可能比直接退出多等待。真实 Emby/CD2、网络及设备环境中的效果仍需验证，源码／合成回归不能替代真实播放验收。

## 下载安装

从本 Release 的实际附件区下载 Windows x64 安装包、同名 `.sha256` 与来源记录；`SHA256SUMS.txt` 列出发行文件摘要。勿将 Source code 压缩包当作客户端安装包。安装器未签名；手动安装前核对 SHA-256 并正常退出客户端。操作说明见[用户指南](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/USER_GUIDE.md)。准确版本、源码和包体身份以附件来源记录为准。
