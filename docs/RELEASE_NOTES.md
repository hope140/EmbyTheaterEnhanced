# v0.4.20 测试版

Windows x64 **Pre-release 测试版**。可手动下载，或在“关于 Enhanced”选择测试通道后主动检查更新。当前正式版仍为 [v0.4.0](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.0)。

## 本次更新

- 修复播放错误提示的关闭与页面历史行为，减少返回后反复确认牵动底层页面的问题；普通对话框及导航保持原流程。
- 增加普通／详细诊断级别，记录原生操作错误、启动属性的实际执行结果和有界启动上下文；低级日志与关键错误分别限流，写入成功后才对引擎记录去重。
- 简化下载、STRM、缓存、诊断、播放内核和字幕外观的说明，保留目录变更、文件删除、日志分享与更新退出等必要提示，不改变对应操作逻辑。
- 修复按规则优先使用原生播放时误报回退的问题；真实失败后的回退及已下载文件优先命中保持。
- 同步用户指南、已知问题和后续范围说明。

## 已知问题

播放成功率退化和提前 EOF 的现场根因仍未确认，115 并发原因尚无证实。本版不增加 EOF 保护、播放自动重试或修改 keep-open，诊断补充不等于已修复这些未知原因。不同服务器、媒体和设备组合仍需实际使用验证。

详细日志在下一次播放生效，不影响当前播放；普通模式仍保留必要错误。关键错误自身有界，快照淘汰、没有后续事件或磁盘不可用仍可能限制日志恢复。日志虽会脱敏，仍可能包含服务器地址和媒体路径，分享前请检查。

## 下载安装

从本 Release 的实际附件区下载 Windows x64 安装包、同名 `.sha256` 与来源记录；`SHA256SUMS.txt` 列出发行文件摘要。勿将 Source code 压缩包当作客户端安装包。安装器未签名；手动安装前核对 SHA-256 并正常退出客户端。操作说明见[用户指南](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/USER_GUIDE.md)。准确版本、源码与测试范围以本版附件来源记录为准，包体核验不代替安装和真实播放验收。
