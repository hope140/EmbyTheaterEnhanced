# v0.3.9 · 安装升级验证测试版

Windows x64 **Pre-release 测试版**，请从本页手动下载。当前正式版为 [v0.3.1](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.3.1)。

## 本次内容

- 在Windows本机完成0.3.6与0.3.8之间的同目录升级、允许降级、卸载后重装和关键文件占用拒绝验证。
- 校验上述过程中的原资料及有效设备标识文件保持。
- 功能代码沿用0.3.8；本版更新0.3.9版本元数据与准确来源记录，重新生成标准安装器。

验证限上述有界场景；UAC拒绝、人工取消、空资料首次启动、真实播放及服务器操作仍未验证。详细结果与固定工具链延后残留说明见[安装验收记录](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/V039_HOST_ACCEPTANCE_CONTRACT.md)。

## 已知问题

多显示器的目标选择和完整退出恢复仍需继续观察。STRM/115内嵌字幕与音轨切换延迟尚未解决。更多内容见[已知问题](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/KNOWN_ISSUES.md)。
