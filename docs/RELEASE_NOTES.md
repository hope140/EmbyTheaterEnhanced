# v0.4.7 测试版

Windows x64 **Pre-release 测试版**。可手动下载，或在“关于 Enhanced”选择测试通道后主动检查更新。当前正式版仍为 [v0.4.0](https://github.com/hope140/EmbyTheaterEnhanced/releases/tag/v0.4.0)。

## 本次更新

- 新增在线提前下载，沿用影片下载按钮，首次选择目录后记住；服务器在线时播放同版本可优先使用已下载文件。
- 支持 STRM／CD2 原始视频来源，并在原下载接口失败时尝试服务器的静态原视频接口；实际响应仍须通过完整视频、长度和来源校验。
- 新增下载管理：暂停、继续、重试、打开文件夹、批量操作及文件位置检查。关闭客户端保留未完成任务，重新登录后按来源和文件校验结果续传或安全重下。
- 剧集菜单统一为“下载全剧”“下载本季”，逐集加入原队列并跳过已有任务；下载完成提示显示具体片名或剧名、季集号和集名。

## 已知问题与验证范围

下载需要服务器在线及账户下载权限，不提供断网启动和离线媒体库。可播放的来源仍可能只有分段流、缺少长度或使用特殊鉴权，不能保证全部可下载；安全续传需要来源支持正确 Range 和强校验器，不满足时从头下载自己的未完成文件。

更改默认目录只影响新任务，已有文件不搬迁。删除任务默认保留文件，另行明确确认才会永久删除经核验的本任务文件。不会自动接管旧下载或扫描清理用户目录。真实 FAT／exFAT、网络盘和移动盘兼容仍需独立验证。

提前下载基础功能已有使用者手动验收反馈；本轮菜单文字和完成提示采用针对性自动测试，未追加完整客户端或安装验收。源码、构建和发布状态见[本版核验记录](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/V047_RELEASE_VERIFICATION.md)。不包含独立预载或缓冲暂存分支。

## 下载安装

从本 Release 的实际附件区下载 Windows x64 安装包与对应 `.sha256` 文件，勿将源码压缩包当作安装包。安装器未签名；手动安装前核对同版本 SHA-256 并正常退出客户端。安装与更新说明见[用户指南](https://github.com/hope140/EmbyTheaterEnhanced/blob/main/docs/USER_GUIDE.md)。
