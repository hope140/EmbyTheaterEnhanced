# Original-container subtitle track mapping

The native adapter resolves an embedded original-container subtitle by its unique container stream index (`MediaStreams.Index` to the non-external mpv subtitle track's `ff-index`) and writes the actual mpv track `id`. External subtitles do not consume embedded IDs and no guessed `sid` is written before `sub-add cached`.

The native service exposes a track table only after the current generation's `file-loaded`. Default selection retains its original selection owner while waiting for playback readiness without blocking unpause. An interactive selection uses a bounded lookup. A missing, duplicate or unavailable identity never falls back to list position; the previous subtitle is disabled and a fixed diagnostic reason is recorded. Stop, replacement, newer selection and route generation changes retire delayed work.

Generated VideoSideData closed-caption tracks retain their existing non-container mapping. DirectStream uses the same mapping only for a proven raw source result: STRM DirectUrl/CD2 URL, an existing mapped mount file, or an identity-checked downloaded file. Eligibility is recomputed per route attempt. Native/server-remux DirectStream retains the output subtitle order contract, but resolves that ordinal to the actual non-external native ID. Source indexes do not prove remuxed output identity. The source/output embedded counts must agree; external metadata rows never consume output ordinals. Extracted internal streams still count as internal. Transcode, generated captions and legacy teletext keep their previous selection contract. This change does not claim to fix that separate mapping boundary or establish a particular user's incident cause.

Validation: `node --test tests/subtitle-selection-ownership.test.cjs tests/native-helper-service.test.cjs tests/native-helper-diagnostics-playback.test.cjs`. For an optional headless real-mpv synthetic check, run `node tools/test-subtitle-track-mapping.cjs --mpv <existing-mpv-executable> --ffmpeg <existing-ffmpeg-executable>`. It exercises the production selection functions, three external-list positions, repeated cached loading and both embedded tracks without loading a product profile. It does not replace installed-client or real-server acceptance.

Add `--reported-layout` to synthesize four audio streams and seven embedded subtitle streams (container indexes 5–11), and exercise default external → first embedded → third embedded selection. This remains synthetic media, not a replay of a private user file.

Add `--early-external` to serve the synthetic container over delayed loopback HTTP while loading the external subtitle at 700 ms. The external track obtains ID 1 before the embedded tracks are discovered; their native IDs then shift even when the external row is last in Emby metadata. The real-mpv probe verifies exact container-index selection despite that discovery order, including Off after a delayed track read.

Use `--native-output-order` for the non-original DirectStream mapping, `--order last` to isolate the normal external-last layout, and `--adapter-source <path>` for a read-only comparison with a baseline adapter. `--observe-only` records actual selections without claiming a pass. These probes remain synthetic and isolated from user sessions.
