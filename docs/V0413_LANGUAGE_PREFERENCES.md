# v0.4.13 语言偏好测试版候选

## 范围与语义

- “播放”中的首选音轨语言支持多选；“字幕”中已有的多选也支持调整顺序。两处设置页仅显示已选语言，打开原有公共选择弹窗后，已选项置顶；可用拖动手柄调整顺序，也可用可聚焦的上／下图标按钮通过键盘或遥控调整。仅这两个选择框启用弹窗排序。列表顺序写入服务端用户配置的逗号分隔字符串。
- 语言代码和显示名来自当前服务器 `getCultures()`。未知代码保持可见且可调整，未修改语言时不重写服务器上取回的原值；清空选择写入空字符串。
- “播放默认音轨”“记住音轨选择”“记住字幕选择”及清除已记轨道保持原接口。记住选轨仍由服务器按媒体记录处理；本版不增加客户端选轨规则，实际轨道以服务器播放信息为准。旧服务器可能仅把逗号值当成单一语言，实际解释需连接目标版本验证。
- 与其他 Emby 客户端共用同一用户配置字段。页面保存前重新读取用户配置，因此未调整的语言字段沿用服务器的新值；同时修改同一字段时，最后一次保存仍可能覆盖前一次。

官方网页参考：[播放模板](https://app.emby.media/settings/playback.html)、[播放脚本](https://app.emby.media/settings/playback.js)、[字幕模板](https://app.emby.media/settings/subtitles.html)、[字幕脚本](https://app.emby.media/settings/subtitles.js)。2026-11-04 读取；当前网页使用 `multiple`、`data-reordering`、`data-joindelimiter=","` 和上述两个用户配置字段。ETE 固定旧 Web 弹层通过可选扩展复用其列表拖放能力，并补可聚焦按钮；未启用的公共弹窗沿用原行为。

## 验收方法

1. 在 ETE “播放”页打开语言弹窗，选择两种音轨语言，用手柄拖动或上／下按钮改变顺序；离开再进入，确认顺序保留。用键盘 Tab／Enter 和遥控方向键／确认键分别操作，移动后焦点应仍在当前语言的可用按钮上。
2. 在“字幕”页对已有多选语言做相同操作；核对清空、未知代码和重进页面的显示。再到官方网页核对同一用户的顺序，反向修改后返回 ETE 核对读取。避免同时在两个客户端修改同一字段。
3. 切换“播放默认音轨”和“记住音轨选择”，复播同一媒体；检查实际轨道、服务器记录及本次语言设置是否互不误写。字幕模式和记住字幕选择也核对一次。不同媒体可用轨道需分别记录，不能只凭设置页保存判定选轨生效。
4. 若需兼容旧服务器，用其测试账户执行相同读写和播放检查，记录服务器版本及其是否理解逗号优先序。不要在现用账户上做破坏性试验。

## 证据边界

本分支运行 Node VM 设置页回归、Web overlay 来源校验和公开源码检查。隔离 Chromium 页面加载冻结版的 ActionSheet、EmbySelect、ItemsContainer、VirtualScroller 和 DialogHelper 组件及本版补丁，复测已选与普通语言行同高、鼠标排序、取消选择、滚动后的行复用及普通多选弹窗；键盘按钮移动后的焦点需等列表重绘完成再恢复。音轨与字幕共用同一弹窗扩展，页面保存分别由 VM 回归覆盖。该页面使用模拟语言数据和服务，未验证 Windows 原生窗口、真实遥控、真实服务端、队列实际操作或拖拽手势；拖放仅检查旧 ItemsContainer 的 `itemdrop` 事件合同。弹窗打开时原 DialogHelper 的全屏容器会接收首次外部点击并关闭弹窗，首次点击不传给背后的设置或窗口按钮；隔离复现中再次点击可触发按钮。若弹窗关闭后按钮仍失效，需要现场录屏或日志继续定位。Windows 测试包、安装包解包回比、真实服务器读回与播放按准确提交另行记录；构建通过不替代现场验收。合并 main、建 Tag、发布 testing 均待单独授权，不发布正式版。
