# 代理协作细则

[AGENTS.md](../AGENTS.md)是协作入口与维护边界；本页集中维护模型建议、分工和交接。开发命令见[贡献指南](CONTRIBUTING.md)，验证证据见[测试与验收](TESTING.md)，CI 路线见[公开 CI](PUBLIC_CI.md)。历史维护记录保存当时事实，不作为当前模型路由或新的操作授权。

## 模型选择与执行设置

主代理沿用用户配置，所有代理执行使用 Standard，Fast 关闭；未经用户明确授权不切换模型、推理强度或服务模式。以下是分工建议，不是自动路由配置，也不要求升级客户端。已有任务约定继续有效。

| 工作 | 建议模型 | 状态与边界 |
| --- | --- | --- |
| 明确规格的测试、脚本与文档；有界检索 | GPT-6 Luna | 保留既有优先路由；输入与验收须明确。 |
| 跨模块实现、复杂接线与整合 | GPT-6.1 Sol | 保留既有优先路由；主代理的实际模型仍由用户配置决定。 |
| 高风险设计、疑难审查与最终复核 | GPT-6 Astra | 保留既有优先路由；不能替代主代理验收。 |
| 视觉检查、目标明确的电脑操作、基于材料的文档整理及有界小修 | GPT-6.1 Terra（`gpt-6.1-terra`） | 新增可选建议，尚未经 ETE 同条件对照验证；不自动替换上述路由。 |

截至 2026-10-26，[Terra 官方模型页](https://developers.openai.com/api/docs/models/gpt-6.1-terra)定位视觉推理、精准电脑操作与清晰写作；[官方模型选择指南](https://developers.openai.com/api/docs/guides/model-selection)还列出有界代码修改。这支持上述试用建议，不构成项目性能或复杂开发能力结论。模型可用性以实际客户端、账号和运行环境为准；Terra 不可用时沿原路由，原路由也不可用则报告限制，不静默换型。

按[官方子代理说明](https://learn.chatgpt.com/docs/agent-configuration/subagents)，仅当自定义代理、显式派发及 `[agents]` 默认值均未覆盖模型或推理强度时，子代理才继承父代理相应设置；显式或配置选择模型而未指定强度时，可能采用该模型默认值。最终以当前运行时实际解析结果为准。已有明确角色设置需要同时记录模型与强度，并先确认当前接口支持。Standard／Fast 服务模式、推理强度和产品模式分别记录，不把编排接口或产品模式标签直接当作 API 的 `reasoning.effort`。本页不提供或改写任何配置文件。

## 主代理与子代理分工

主代理负责用户沟通、需求与授权解释、基线和范围确认、接口归属、整合审查及最终验收。子代理的完成报告是待核对输入；主代理核对实际差异与证据后再向用户报告。是否创建子代理仍按当前用户要求和运行环境规则执行，本页不自动授权并行。

只并行能够独立完成的部分。按文件／模块或只读审查边界派发，明确单一写入负责人；同一文件不并发写，公共入口、共享合同及整合文档由主代理协调。依赖上游产物的任务等待已核验的提交或文件清单，不消费另一任务未完成的工作树。发现重叠、基线漂移或必须改动范围外文件时，先回报并停止相关写入。

每次派发至少明确：

- 输入：仓库、准确基线 SHA、相关合同、已知限制及已有工作。
- 边界：负责文件／模块、允许的操作、禁止触及的任务与资源；只读审查须明确不编辑。
- 输出：预期差异或审查结论、验证命令与验收标准、是否等待结果及整合负责人。
- 停止条件：范围冲突、权限／环境受阻、来源不确定或无法满足验收时，报告已完成部分和待解决项。

独立分支／工作树用于隔离改动，不代表拥有额外权限。子代理继承当前权限与审批限制；“只读审查”的文字要求不产生独立只读沙箱。提交、推送、PR、合并、发布、部署、安装及现用客户端操作仍受当前用户授权约束，不能借委派绕过限制。

## 验证与交接

按[测试与验收](TESTING.md#证据与失败记录)记录证据与失败，按[CI 结果与源码身份](PUBLIC_CI.md#result-identity-and-handoff)核对准确来源；单元、材料或云端构建通过都不能代替实际客户端验收。文档整理也须核对实际 CI 路由，不能为获得轻量路线更改白名单或跳过既有门禁。

交接先写结果与剩余阻塞，再给必要依据：

| 项目 | 必要内容 |
| --- | --- |
| 来源与范围 | 基线／当前 SHA、分支、改动文件、工作树是否干净；未提交内容单列。 |
| 分工与设置 | 主／子代理角色、实际模型／强度／服务模式及变更原因；仅有派发配置时标为配置值，无法确认的实际身份保留未知。 |
| 验证 | 命令、环境、结果／失败／跳过／未执行项、对应证据；CI 与构建产物按合同记录来源。 |
| 阻塞与下一步 | 准确动作和目标、原因、已完成工作、动作是被拒绝／等待中／结果不确定，以及继续所需条件。 |

权限拒绝后停止该动作；不确定是否已执行时先检查实际状态。不能静默换路径、账号、环境或代理重试受限动作，也不能把夹具修正或环境补齐后的复验改写成初次通过。公开仓库只保存可复现方法和必要脱敏结论；个人账号、路径、凭据、私人对话、原始诊断与派发流水保存在仓库外，历史型号和验收事实不追溯改写。
