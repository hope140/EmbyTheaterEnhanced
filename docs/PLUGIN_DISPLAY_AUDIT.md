# 插件显示对照与验收范围

2026-10-14补充：选择控件新增垂直几何门禁，要求选中值和箭头在实际输入框内、说明从其下方开始。原多选固定占位在空标题时失准，当前采用共享输入网格行；实际DOM覆盖空标签与长标签换行。仅检查页面水平溢出不足以证明文字无重叠。

本轮集中核对神医助手 6 个 GenericUI 页面、Madby 8 个 GenericUI 页面、Backup 主页及 Restore/Extract 两个对话框模板。Chapter API 的四个页面、Episode Refresh 和 TheIntroDB 主入口另作邻接回归。保留客户端宿主主题和字体，不将它们与服务端浅色主题的像素差异当作组件失败。

| 组件或行为 | 发现的共用差异 | 本轮处理及证据 |
| --- | --- | --- |
| 页面标题与说明 | 页头、正文和根分组重复 | 页头拥有普通页面标题；仅消除相同根分组内容，Dialog/Wizard 保留自己的标题 |
| 状态卡片 | 成功图标为实体文字，卡片结构和高度不一致 | 窄映射 Material 图标；限定组件背景、圆角、最小高度及空行。真实字体加载、截图和计算样式对照 |
| 按钮与列表图标 | StandardIcon 未识别，父行可能误取子行图标 | 合法名称或单个私用码点映射，图标归属限定当前行；合成 DOM 验证 |
| 开关与条件 | 旧复选框外观，替换后旧节点导致分组只读/隐藏失效 | 复用原 emby-toggle；状态 Map 绑定新输入，保留 readonly/disabled/hidden 和父分组约束 |
| 分组和按钮组 | 说明归属错误，按钮组状态遗漏 | 只移动直接子节点；组状态作用于所属控件，变化后可恢复且不覆盖只读基线 |
| 文本与链接 | 纯文本、HTML 消费和链接出口不同 | 按既有消费者保留单次转义；合法 HTTP(S) 走原 shell，禁止活动协议及已识别认证字段 |
| 多选、单选与进度 | 来源值、长标签和边界需核对 | 静态/动态来源真实 DOM 保真；零进度、有限最大值、长文本换行和窄窗口合成验证 |
| 传统对话框关闭 | 模板声明 emby-dialogclosebutton，客户端未注册 | 插件模板解析前预加载窄兼容组件；只关闭所属 dialog，不提交表单、不执行业务命令 |
| 页签、页头与切换 | 点击、选中态和迟到更新须保持 | 复用原生页签及归属保护；逐页读取、原生点击往返和普通页面清理有独立证据 |

14 个真实 GenericUI 页面与网页分别在正常宽度、800px 窗口及 125% 缩放下检查字段、文本、图标、隐藏/禁用、分组、水平溢出，并生成私有对照截图。状态卡片以计算样式核对尺寸、间距和图标；宿主主题、字体及原生图标字体不同不表示相同像素。页面路由检查不替代真实页签按钮点击，写入交互只在合成服务验证。

Backup 对话框只加载实际模板并填入虚构选项，不调用恢复/提取 controller 或执行操作。关闭按钮通过真实隐藏 DOM 点击及原 helper 的关闭事件验证，提交计数为零；隐藏窗口的动画检查需要后台绘制，不代表用户前台视觉验收。真实服务 UI/Command 和完成的非读取请求均为零。

数据、截图和原始服务端资源只留在私有审计目录，不进入代码或可分享包。产物清单绑定准确 sourceCommit、源码和生成器、完整 runtime 以及验证回执；中间工作副本结果不冒充正式产物。

未覆盖真实配置保存、备份/恢复、播放、远控、安装或任意未来第三方插件。当前页面没有声明的 DataGrid/PivotGrid 仍保持不支持；Dialog/Wizard、错误和恶意输入采用合成用例验证。最终前台验收应一次浏览三个插件的全部页签和上述显示组件，并只记录可见结果。
